# 04 — Examination Model

## Mid-semester structure (confirmed)
- Three questions, all compulsory.
- Question 1: 20 marks.
- Question 2: 20 marks.
- Question 3: 10 marks.
- Total: 50 marks.
The engine must prepare the full compulsory paper. It must not treat any question as optional.

## End-semester structure (CONFIRMED)
Confirmation recorded: Section A has 2 compulsory questions each worth 20 marks; Section B offers 5 questions and the student chooses 3 each worth 20 marks; overall 7 questions are offered and 5 are answered, totalling 100 marks. Owner confirmation is recorded in D-01 of `14-open-decisions.md`.

## Exam record fields
- module ID;
- exam type (`MIDSEM`, `ENDSEM`, other if approved);
- date and start time, each with source/status;
- duration;
- timezone;
- marks available;
- question groups/sections;
- number of questions offered;
- number compulsory;
- number to answer;
- marks per question;
- theory/practical distribution;
- known topic coverage;
- source document and verification status.

## Preparation logic
- Exam structure can inform preparation before exact dates are known.
- Generic preparation should include all compulsory content.
- For optional sections, prepare broad enough coverage to make a genuine choice; do not study only the minimum number of optional questions.
- Exact date-driven priority requires a reliable date and module mapping.
- A missing timetable does not stop normal syllabus coverage or revision.
- Once dates arrive, prioritize imminent papers without silently abandoning other modules.

## Proposed preparation windows (not fixed policy)
A starting heuristic for simulation:
- 21+ days: coverage and consolidation;
- 14–20 days: consolidate and revise;
- 7–13 days: targeted practice and weak-topic work;
- 1–6 days: active recall, mock questions and focused review;
- exam day: no normal two-hour session by default.
These are provisional heuristics. The engine must adapt when only a short preparation window remains and must report infeasibility honestly.

## Readiness
Do not calculate readiness from scheduled/completed time alone. Use topic coverage, recall/quiz evidence, repeated retrieval, practical performance and unresolved weak areas. Show uncertainty when evidence is sparse.
