# 11 — Mobile-First Screen Inventory (APPROVED 2026-11-16)

The owner approved the screen inventory, navigation and design direction on
2026-11-16. The screens below are implemented in Compose with Material 3 using
the approved palette. This document remains the reference inventory; changes to
navigation or new screens still need owner review.

## Implemented first-run flow
1. Welcome and product explanation.
2. Study commitment explanation (120 minutes, weekdays, weekends off).
3. Academic year/semester setup.
4. Registered module setup.
5. Study availability setup.
6. Progressive data status: explain that outlines and timetables can be added later.
7. Permission education, requested only when needed.
8. First plan preview and confirmation.

## Primary navigation
- **Today:** current session, next action, progress and today's plan.
- **Academics:** semester, modules, outlines and topic coverage.
- **Exams:** exam structures, dates, preparation and readiness.
- **Progress:** recorded sessions, interruptions and explicit learning evidence.
- **Settings:** study availability, enforcement setup, privacy, backup and accessibility.

## UX requirements
- Keep active session visually quiet.
- Do not show a dense full-semester timetable during study.
- Display one primary action.
- Distinguish official, estimated, received and conflicting data.
- Avoid streak-shame and punitive backlog counters.
- Use readable text, scalable fonts, high contrast and accessible controls.
- Do not use a red warning for ordinary missed sessions.
- Explain why a topic was selected in a short sentence.
