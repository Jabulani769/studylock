# Version 1.0.0 — first version

This is the first version of StudyLock (`versionCode = 1`, `versionName = "1.0.0"`).

## Included
- One continuous 120-minute study session on each eligible weekday; weekends are rest days.
- Deterministic, local academic planning with infeasible-plan redesign proposals.
- Local profile with name-derived initial and optional local photo.
- First-run permission explanations and inexact weekday reminders.
- Document reader for PDF, images and plain text, with topic-linked materials.
- Appearance settings, local backups, honest focus-support status.
- Icon-based removal controls and bottom-right chevron page navigation in the reader.

## Limitations
- No accounts, cloud sync, analytics or remote services.
- No universal app blocking; the app states what Android can and cannot enforce.
- No measured improvement claimed for the earlier performance work; a quiet-device A/B test is still required.
- Android 16 has not been tested.
